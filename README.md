# WARDOGS — YouTube Shorts / TikTok Config Guide (`sg.ShadowQuality=4`)

Репозиторий содержит готовые вертикальные видеоролики (`1080×1920`, 30 FPS) и генератор `generate_videos.py` по отключению теней и повышению контрастности моделей/FPS в **WARDOGS** на основе [гайда Bryce в Steam Community](https://steamcommunity.com/sharedfiles/filedetails/?id=3809577033).

## Готовые видеофайлы в репозитории

| Файл | Длительность | Описание |
| :--- | :---: | :--- |
| **`wardogs_shorts_viral_1080x1920.mp4`** | **33.8 сек** | **Главная вирусная версия для YouTube Shorts / TikTok:** убраны мёртвые паузы в начале и между фразами, мгновенный хук на 0.08 сек, бит с 0:00 с сайдчейном, звуковые эффекты (SFX), реальные скриншоты из игры и финальная шпаргалка с бесшовным циклом (Seamless Loop). |
| **`wardogs_otkluchenie_teney_konfig_1080x1920.mp4`** | **33.8 сек** | Готовая к загрузке копия вирусной версии с SEO-именем файла для YouTube Shorts. |
| **`wardogs_config_1080x1920.mp4`** | **44.3 сек** | Полная версия 1:1 по хронометражу с исходной озвучкой (`wardogs2_audio.mp3`), где исправлены все наложения текста, добавлены реальные скриншоты из игры и звуковые акценты. |

## Что исправлено и улучшено

1. **Устранены все наложения текста и графические баги:**
   - В Шаге 3 (`sg.ShadowQuality=`) цифра `0` и цифра `4` больше не рисуются друг поверх друга: `0` аккуратно зачёркивается слева, а через стрелку отдельно загорается зелёная `4` и бейдж `✓ ТЕНИ В НОЛЬ!`.
   - В нижнем тумблере Шага 3 убрано наложение строк `ТЕНИ: ВКЛ` и `ТЕНИ: ВЫКЛ`.
   - В Шаге 2 (Блокнот) устранён наезд пункта меню `Вид` на поле поиска и исправлен баг, из-за которого при подсветке строки весь текст окна становился чёрным на тёмном фоне.
   - В блоке «Результат» увеличены отступы итоговой плашки `БЕЗ ТЕНЕЙ — МОДЕЛИ ИГРОКОВ ВИДНО СРАЗУ`, текст не касается границ рамки.
2. **Вместо ИИ-генерации использованы реальные скриншоты из игры (`assets/`):**
   - В Хуке (0:00) и в Результате демонстрируются **3 реальные пары скриншотов из игры WARDOGS** (тёмный ангар со снайперкой `SV98`, проход между зданиями `116 FPS ➔ 172 FPS`, промзона и силосы `126 FPS ➔ 177 FPS`) с анимированной шторкой сравнения.
   - В Шагах 1–3 добавлены реальные скриншоты Проводника Windows 11 (`WindowsClient/GameUserSettings.ini`), Блокнота Windows 11 (`sg.ShadowQuality=4`) и меню настроек графики WARDOGS.
3. **Оптимизация под алгоритмы YouTube Shorts:**
   - Подробный пакет заголовков, тегов, описания и закреплённого комментария находится в файле [`wardogs_config_upload_pack.md`](./wardogs_config_upload_pack.md).
